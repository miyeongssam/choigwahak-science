꼭 참고

이 자료는 비상교육 교과서(세포와 물질대사 104~113쪽)를 바탕으로 만들었습니다. 다른 교과서는 실험 조건의 표현과 그림이 다를 수 있습니다. 「알아보려 한 것」은 교과서 본문을 바탕으로 정리한 문장입니다.

꼭 외울 다섯 줄

① 엥겔만 해캄 + 프리즘 → 청자색광 · 적색광에서 광합성이 활발하다.
② 힐 엽록체 + 옥살산 철(Ⅲ) → 이산화 탄소 없이도 산소가 발생한다.
③ 루벤 클로렐라 + 18O → 산소는 물에서 유래한다.
④ 벤슨 빛과 이산화 탄소 조건 → 명반응 다음에 탄소 고정 반응이 일어난다.
⑤ 캘빈 클로렐라 + 14CO2 → 최초 산물은 3PG, 캘빈 회로를 밝혔다.

과학자별 실험

엥겔만1883년

사용한 것
해캄, 산소 세균(호기성 세균), 프리즘
알아보려 한 것
어떤 색(파장)의 빛에서 광합성이 활발하게 일어날까?
실험
프리즘을 통과해 여러 색으로 나뉜 빛을 해캄에 비추고, 해캄 주변에 산소 세균이 어디에 모이는지 관찰하였다.
결과
산소 세균이 청자색광과 적색광을 받은 부분에 많이 모였다.
알게 된 것
광합성은 청자색광과 적색광에서 활발하게 일어난다. 엽록소가 잘 흡수하는 빛에서 광합성이 활발하므로, 광합성에 필요한 빛에너지는 주로 엽록소에서 흡수된다.

힐1939년

사용한 것
엽록체 추출액(질경이 잎), 옥살산 철(Ⅲ)
알아보려 한 것
광합성에서 산소가 나올 때 이산화 탄소가 꼭 있어야 할까?
실험
엽록체 추출액에 옥살산 철(Ⅲ)을 넣고, 시험관 안의 공기를 뺀 다음(이산화 탄소 없음) 빛을 비추었다.
결과
이산화 탄소가 없는데도 산소가 발생하였고, 옥살산 철(Ⅲ)이 옥살산 철(Ⅱ)로 환원되었다.
알게 된 것
빛에너지를 흡수하면 물이 분해되어 산소가 발생하고, 이때 방출된 전자가 옥살산 철(Ⅲ)을 환원시킨다. 엽록체에서 옥살산 철(Ⅲ)과 같은 역할을 하는 물질은 NADP+이다.

루벤1941년

사용한 것
클로렐라, 산소의 동위 원소 18O
알아보려 한 것
광합성에서 발생하는 산소는 물에서 올까, 이산화 탄소에서 올까?
실험
클로렐라 배양액에 18O로 표지된 물(H218O)과 18O로 표지된 이산화 탄소(C18O2)를 각각 공급하고, 발생하는 산소를 분석하였다.
결과
H218O를 준 쪽에서만 18O2가 발생하였다. C18O2를 준 쪽에서는 보통의 O2가 발생하였다.
알게 된 것
광합성에서 발생하는 산소는 물에서 유래한다.

벤슨1949년

사용한 것
식물, 빛과 이산화 탄소의 공급 조건
알아보려 한 것
빛이 필요한 단계와 이산화 탄소가 필요한 단계는 어떤 관계일까?
실험
식물에 빛과 이산화 탄소를 주는 조건을 달리하면서 광합성 속도를 측정하였다.
결과
빛이 없으면 이산화 탄소가 있어도 광합성이 일어나지 않았다. 빛을 먼저 비춘 뒤 이산화 탄소를 공급하면 빛이 없어도 잠시 동안 광합성이 일어났다. 빛과 이산화 탄소를 함께 주면 광합성이 계속 일어났다.
알게 된 것
광합성은 빛을 이용하는 명반응과 이산화 탄소를 포도당으로 합성하는 탄소 고정 반응으로 나뉘고, 명반응 뒤에 탄소 고정 반응이 일어난다. 명반응에서 만들어진 물질(ATP, NADPH)이 공급되어야 탄소 고정 반응이 일어난다.

캘빈1956년

사용한 것
클로렐라, 탄소의 방사성 동위 원소 14C, 종이 크로마토그래피, X선 필름
알아보려 한 것
이산화 탄소는 어떤 물질들을 거쳐 포도당이 될까?
실험
클로렐라에 14CO2를 공급하고 빛을 비춘 뒤, 일정 시간마다 클로렐라를 채취하여 광합성을 정지시켰다. 생성된 물질을 추출해 종이 크로마토그래피로 두 번(1차 · 2차 전개) 분리하고 X선 필름에 밀착하였다.
결과
14CO2에 3초 노출했을 때는 3PG만 14C로 표지되었다. 30초 노출했을 때는 PGAL, 6탄당 인산 등 여러 물질이 표지되었다.
알게 된 것
탄소 고정 반응에서 최초로 생성되는 물질은 3PG이다. 노출 시간을 늘려 가며 새로 표지되는 물질을 확인하여, 이산화 탄소로부터 탄수화물이 합성되는 경로(캘빈 회로)를 밝혔다.

헷갈리는 것 바로잡기

힐과 루벤

둘 다 「산소는 물에서 나온다」와 이어지지만 한 일이 다르다. 힐은 엽록체 추출액에 옥살산 철(Ⅲ)을 넣어, 이산화 탄소가 없어도 산소가 발생함을 보였다. 루벤은 클로렐라에 동위 원소 18O를 써서, 발생한 산소가 물에서 왔음을 직접 확인하였다.

엽록체 · 옥살산 철 = 힐 / 클로렐라 · 18O = 루벤

벤슨과 캘빈

벤슨의 실험은 빛과 이산화 탄소를 주는 조건을 바꾸며 광합성 속도를 잰 실험이다. 알게 된 것은 명반응과 탄소 고정 반응의 순서이다. 캘빈의 실험은 14CO2를 주고 시간에 따라 어떤 물질이 만들어지는지 추적한 실험이다. 알게 된 것은 최초 산물 3PG와 캘빈 회로이다.

조건 바꾸고 속도 측정 = 벤슨 / 14C로 물질 추적 = 캘빈

3PG와 RuBP의 양 변화는 벤슨 실험이 아니다

「빛을 끊으면 3PG와 RuBP가 어떻게 변하나」는 벤슨의 실험이 아니라 캘빈 회로를 묻는 문제다. 벤슨의 실험 그래프는 세로축이 광합성 속도이다.

조건3PGRuBP까닭
빛 차단증가감소ATP · NADPH가 없어 3PG가 환원되지 못하고 RuBP가 재생되지 못한다.
CO2 차단감소증가RuBP가 CO2와 결합하지 못해 3PG가 새로 생기지 않는다.

흡수 스펙트럼과 작용 스펙트럼

흡수 스펙트럼은 파장에 따른 빛 흡수율, 작용 스펙트럼은 파장에 따른 광합성 속도이다. 두 그래프는 거의 일치하지만 완전히 같지는 않다. 엽록소 a · b만 있는 것이 아니라 카로티노이드 같은 다른 색소가 있어, 엽록소가 잘 흡수하지 못하는 파장의 빛도 흡수해 엽록소에 전달하기 때문이다.

예상 질문과 답

답을 먼저 외우고, 「답 모두 가리기」를 눌러 질문만 보고 써 본다. 질문을 누르면 그 답만 열리고 닫힌다.

순서 · 한눈에

1.다섯 과학자를 실험한 해 순서대로 쓰시오.

엥겔만(1883) → 힐(1939) → 루벤(1941) → 벤슨(1949) → 캘빈(1956)

2.동위 원소를 사용한 과학자 두 명과 각각 사용한 동위 원소는?

루벤은 산소의 동위 원소 18O, 캘빈은 탄소의 방사성 동위 원소 14C를 사용하였다.

3.클로렐라를 사용한 과학자 두 명은?

루벤과 캘빈이다. 엥겔만은 해캄, 힐은 엽록체 추출액을 사용하였다.

엥겔만

4.엥겔만의 실험에서 산소 세균이 청자색광과 적색광을 받은 부분에 많이 모인 까닭은?

청자색광과 적색광에서 해캄의 광합성이 활발하게 일어나 산소가 많이 발생하였기 때문이다.

5.엽록소의 흡수 스펙트럼과 엽록체의 작용 스펙트럼을 비교하여 알 수 있는 것은?

두 그래프의 모양이 비슷하므로, 엽록소가 잘 흡수하는 청자색광과 적색광에서 광합성이 활발하게 일어난다. 즉 광합성에 필요한 빛에너지는 주로 엽록소에서 흡수된다.

6.작용 스펙트럼이 엽록소 a · b의 흡수 스펙트럼과 완전히 일치하지 않는 까닭은?

엽록소 a · b 외에 카로티노이드와 같은 다른 색소가 엽록소가 잘 흡수하지 못하는 파장의 빛을 흡수하여 엽록소에 전달하므로, 그 파장의 빛에서도 광합성이 일어나기 때문이다.

힐 · 루벤

7.힐의 실험에서 옥살산 철(Ⅲ)이 옥살산 철(Ⅱ)로 환원된 까닭은?

빛에너지를 흡수하여 물이 분해될 때 방출된 전자를 옥살산 철(Ⅲ)이 받았기 때문이다.

8.힐의 실험에서 옥살산 철(Ⅲ)과 같은 역할을 하는 엽록체의 물질은?

NADP+이다. NADP+는 전자를 받아 NADPH로 환원된다.

9.힐의 실험으로 알 수 있는 사실은?

이산화 탄소가 없어도 빛을 비추면 엽록체에서 산소가 발생한다. 즉 산소의 발생에는 이산화 탄소가 필요하지 않고 전자를 받는 물질이 필요하다.

10.루벤의 실험에서 발생한 산소는 각각 무엇에서 유래한 것인가?

H218O를 공급했을 때 발생한 18O2와 C18O2를 공급했을 때 발생한 O2는 모두 물에서 유래한 것이다.

11.힐의 실험과 루벤의 실험의 차이는?

힐은 엽록체 추출액과 옥살산 철(Ⅲ)을 사용하여 이산화 탄소가 없어도 산소가 발생함을 보였고, 루벤은 클로렐라와 동위 원소 18O를 사용하여 발생하는 산소가 물에서 유래함을 직접 확인하였다.

벤슨 · 캘빈

12.벤슨의 실험에서 빛을 먼저 비춘 뒤 이산화 탄소를 공급하면 빛이 없어도 잠시 광합성이 일어난 까닭은?

빛을 비추는 동안 명반응에서 만들어진 물질(ATP, NADPH)이 남아 있어, 이를 이용해 탄소 고정 반응이 잠시 일어났기 때문이다.

13.벤슨의 실험에서 빛이 없어진 뒤 광합성 속도가 곧 감소한 까닭은?

명반응이 일어나지 않아 ATP와 NADPH가 더 공급되지 않고, 남아 있던 ATP와 NADPH가 모두 사용되었기 때문이다.

14.벤슨의 실험 결과로 알 수 있는 사실은?

광합성은 명반응과 탄소 고정 반응으로 나뉘며, 명반응이 먼저 일어나고 명반응에서 만들어진 물질이 공급되어야 탄소 고정 반응이 일어난다.

15.캘빈의 실험에서 이산화 탄소로부터 최초로 생성되는 물질은?

3PG(3-인산글리세르산)이다. 14CO2에 3초 노출했을 때 3PG만 14C로 표지되었기 때문이다.

16.14CO2에 3초 노출했을 때와 30초 노출했을 때의 결과를 비교하여 알 수 있는 사실은?

시간이 지날수록 14C로 표지되는 물질의 종류가 늘어나므로, 이산화 탄소가 3PG를 거쳐 PGAL, 6탄당 인산 등 여러 물질로 차례로 전환되면서 포도당이 합성됨을 알 수 있다.

17.캘빈의 실험에서 일정 시간마다 광합성을 정지시킨 까닭은?

그 시각까지 만들어진 물질만 확인하여, 물질이 생성되는 순서를 알아내기 위해서이다.

빛 · 이산화 탄소를 끊었을 때

18.광합성 중인 식물에서 빛을 차단하면 3PG와 RuBP의 양은 어떻게 변하는가?

3PG는 증가하고 RuBP는 감소한다. 명반응이 멈추어 ATP와 NADPH가 공급되지 않으므로 3PG가 PGAL로 환원되지 못해 쌓이고, RuBP는 재생되지 못한 채 이산화 탄소와 결합해 소모되기 때문이다.

19.광합성 중인 식물에서 이산화 탄소 공급을 차단하면 3PG와 RuBP의 양은 어떻게 변하는가?

3PG는 감소하고 RuBP는 증가한다. RuBP가 이산화 탄소와 결합하지 못해 3PG가 새로 만들어지지 않고, 이미 있던 3PG는 PGAL을 거쳐 RuBP로 재생되기 때문이다.
