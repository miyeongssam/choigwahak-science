# 온도-평형상수 탐구 (K vs T) — 최과학 학습 앱

화학 평형상수 K와 온도 T의 관계를 반트호프 식으로 인터랙티브하게 탐구하는 모바일 학습 앱입니다.

---

```
chem-equilibrium/

```

## 🚀 학원 홈페이지 업로드 방법

### 1단계: 학원 홈페이지 서버에 파일 업로드

`chem-equilibrium` **폴더 전체**를 학원 홈페이지의 원하는 경로에 그대로 업로드합니다.

예시 경로:
```
https://choigwa.com/apps/chem-equilibrium/
```

### 2단계: HTTPS 확인 (중요!)

**PWA(앱 설치)는 HTTPS에서만 작동합니다.**

- ✅ `https://choigwa.com/...` — OK
- ❌ `http://choigwa.com/...` — 설치 불가

학원 홈페이지가 이미 HTTPS면 자동으로 됩니다. 호스팅 업체에 SSL 인증서가 적용되어 있는지 확인하세요 (요즘은 거의 기본).

### 3단계: 접속 테스트

브라우저로 `https://choigwa.com/apps/chem-equilibrium/` 접속해서 정상 작동 확인.

## 📱 학생용 설치 가이드 (학생들에게 안내할 내용)

학원 홈페이지에서 앱 페이지 링크를 클릭한 후:

### 📱 아이폰 (Safari)

1. 하단 **공유 버튼** (□ ↑) 터치
2. **"홈 화면에 추가"** 선택
3. 오른쪽 위 **"추가"** 터치
4. 홈화면에 `K vs T` 아이콘 생성됨

### 📱 안드로이드 (Chrome)

1. 우측 상단 **⋮ 메뉴** 터치
2. **"홈 화면에 추가"** 또는 **"앱 설치"** 선택
3. **"설치"** 또는 **"추가"** 터치
4. 홈화면에 아이콘 생성됨

설치 후에는 **인터넷 없이도** 작동합니다.

## 🎓 학습 기능

- **ΔH° 슬라이더** (−100 ~ +100 kJ/mol): 발열/흡열 반응 전환
- **ΔS° 슬라이더** (−200 ~ +200 J/mol·K): 점근선 K∞ 위치 조절
- **온도 범위 슬라이더** (500 ~ 5000 K): 좁은 구간(지수형) vs 넓은 구간(S자) 비교
- **선형 ↔ 로그 스케일 토글**: 같은 함수의 두 표현 비교
- **반트호프 식 + 점근선 + 변곡점 실시간 계산**

### 학생들이 직접 확인할 수 있는 개념

1. 발열 반응: 온도↑ → K↓
2. 흡열 반응: 온도↑ → K↑
3. 좁은 구간만 보면 지수형, 넓게 보면 S자형
4. 점근선 K∞ = e^(ΔS°/R)
5. 변곡점 T* = |ΔH°|/(2R)

## ❓ 문제 해결

**Q. 홈화면 추가 버튼이 안 보여요**
→ HTTPS 확인. http:// 면 PWA 작동 안 함.

**Q. 그래프가 안 나와요**
→ 처음 한 번은 인터넷 연결 필요 (Chart.js 로드). 이후엔 오프라인 OK.

**Q. 업데이트했는데 학생 앱이 바뀌지 않아요**
→ `sw.js` 파일 안의 `CACHE_NAME = 'chem-equilibrium-v1'` 를 `v2`, `v3`로 변경 후 재업로드. 학생 앱이 자동 갱신됨.
