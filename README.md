# 최과학 수업 앱 · 웹 자료 지도

최과학 과학전문학원의 수업용 앱과 웹 자료를 모아 둔 곳입니다.
주소는 모두 `https://miyeongssam.github.io/choigwahak-science/` 뒤에 폴더 이름을 붙입니다.

새 자료를 넣으면 이 표에 한 줄을 더합니다. 폴더 이름은 주소이므로 바꾸지 않습니다.
새 폴더 이름: 수행평가 `suhaeng-주제-학교`, 개념 정리 `jeongri-주제`, 시뮬 `sim-주제`.
