# 📅 매달 내용 업데이트 방법 (선생님용)

학생은 앱을 **다시 설치할 필요가 전혀 없습니다.** 선생님이 GitHub에 새 문제 파일만 올리면, 학생이 앱을 열 때 자동으로 최신 내용이 불러와집니다.

매달 할 일은 딱 **2가지**입니다.

---

## ① 새 차시 문제 파일 추가

1. Claude에게 다음 달 학습지 PDF를 주고 "이 차시 문제 만들어줘" 라고 하면, `set_8cha.json` 같은 새 문제 파일을 만들어 드립니다.
2. GitHub 레포 → `flashcard-app/data/` 폴더로 들어가기
3. **Add file → Upload files** → 새 `set_8cha.json` 드래그 → **Commit changes**

## ② 목록 파일에 한 줄 추가

1. `flashcard-app/data/index.json` 파일 클릭 → 연필(✏️) Edit
2. `sets` 목록 안에 새 차시를 한 칸 추가:

```json
{
  "id": "8cha",
  "title": "고1 통합과학 8차시 ○○○",
  "desc": "OX ○○ · 카드 ○○",
  "file": "data/set_8cha.json",
  "date": "2026-07-20"
}
```

3. **Commit changes**

끝! 학생이 앱을 열면 새 차시가 목록에 나타납니다.

---

## 💡 참고
- **앱 본체(index.html)는 건드릴 필요 없습니다.** 문제 데이터만 바꾸면 됩니다.
- 문제 데이터는 "네트워크 우선"으로 불러오므로, `sw.js`의 버전을 올리지 않아도 새 내용이 반영됩니다.
- 앱 디자인이나 기능 자체를 바꿀 때만 `sw.js`의 `VERSION = 'v1.0.0'` 을 `v1.0.1` 등으로 올리면 됩니다.
- 기존 차시 내용을 고칠 때는 해당 `set_○cha.json` 파일을 Edit 후 Commit 하면 됩니다.
