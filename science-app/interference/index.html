파동의 간섭물리 · 물결파 수조에서 두 파원 S₁, S₂의 보강 · 상쇄 간섭

밝은색 = 마루, 어두운색 = 골 보강 간섭선 상쇄 간섭선(마디선)
수조를 눌러(클릭해) 점 P를 찍어 보세요. P에서 두 파원까지의 거리와 경로차를 알려 줘요.

파원과 파동

두 파원의 위상

보조선

정리

두 파원에서 점 P까지 거리를 r₁, r₂라 하면 경로차 = |r₁ − r₂| 예요.

보강 간섭 (위상 같은 두 파원): 경로차 = 반파장의 짝수 배 = mλ
→ 마루와 마루, 골과 골이 만나 크게 진동해요.

상쇄 간섭 (위상 같은 두 파원): 경로차 = 반파장의 홀수 배 = (m + ½)λ
→ 마루와 골이 만나 거의 진동하지 않아요. 이 점들을 이은 선이 마디선이에요.

(m = 0, 1, 2, …)

위상이 반대인 두 파원이면 조건이 서로 바뀌어요.
경로차 = 반파장의 짝수 배 → 상쇄, 홀수 배 → 보강.
그래서 수직이등분선(경로차 0) 위가 마디선이 돼요.

간격 d를 넓히거나 파장 λ를 줄이면 (같은 물에서 진동수를 높이면) 마디선이 많아지고 촘촘해져요.
