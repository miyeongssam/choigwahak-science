# 최과학 과학 (학습 앱 하나로 합치기)

학생은 앱 **하나만** 설치하면 됩니다. 과목별 문제, 움직이는 그림, 공부 도구가 모두 들어 있습니다.

- 주소: https://miyeongssam.github.io/choigwahak-science/science-app/
- 설치 방법
  - 아이폰: Safari로 주소 열기 → 아래쪽 공유 버튼(□↑) → 「홈 화면에 추가」
  - 안드로이드: Chrome으로 주소 열기 → 오른쪽 위 ⋮ → 「홈 화면에 추가」 또는 「앱 설치」
- 새 앱을 추가하거나 문제를 고쳐도 학생은 **다시 설치하지 않아도 됩니다.** 앱을 열 때 최신 내용을 받아 옵니다.

## 폴더 구조

| 번호 | 폴더 | 내용 |
|---|---|---|
| 1 | `index.html`, `apps.json` | 홈 화면, 앱 목록(목록은 `apps.json`만 고치면 바뀜) |
| 2 | `common/` | 모든 앱이 같이 쓰는 디자인·문제 풀이 화면 |
| 3 | `quiz/` | 암기 문제(통합과학·화학·오답 노트). 문제 파일은 `quiz/data/` |
| 4 | `neutral/` | 중화 반응의 양적 관계 |
| 5 | `shm/` `interference/` `doppler/` `projectile/` | 물리 |
| 6 | `ion-puzzle/` `elements/` `eq-kt/` `n2o4/` | 화학 |
| 7 | `atp/` `etc/` `cycles/` | 생명 |
| 8 | `timer/` `graph/` | 공부 도구 |
| 9 | `sw.js` | 오프라인 저장(앱 기능을 바꾸면 `VERSION` 숫자를 올림) |

## 암기 문제 추가·수정 (매달 할 일)

문제는 단원별 파일 하나에 들어 있습니다. 예: `quiz/data/통합과학2/05_산과염기의중화반응.json`

1. Claude에게 학습지 PDF를 주고 "○○ 단원 문제 파일 만들어 줘"라고 요청합니다. 파일 형식은 아래와 같습니다.
2. GitHub에서 그 파일을 덮어쓰거나 새 파일을 올립니다.
3. **새 단원 파일**을 추가했다면 `quiz/data/books.json`의 해당 교재 `units` 목록에 한 줄을 추가합니다.

```json
{
  "대단원": "I. 변화와 다양성",
  "중단원": "화학 변화",
  "소단원": "산과 염기의 중화 반응",
  "cards": [
    { "번호": 1, "유형": "OX", "문제": "…", "정답": "O", "해설": "…", "난이도": "중", "출처": "여고1 기말" },
    { "번호": 2, "유형": "단답형", "문제": "…", "정답": "중화점", "해설": "", "난이도": "중", "출처": "" }
  ]
}
```

- `유형`이 `OX`이면 O/X 버튼으로 풉니다.
- `단답형`은 같은 단원의 다른 단답 정답을 오답 보기로 써서 ①~⑤ 문제로 바꿔 냅니다. 문제 안에 `(정지 관성 / 운동 관성)`처럼 고를 말이 있으면 그 말들이 보기가 됩니다.
- `서술형`은 정답을 보고 스스로 채점합니다.
- 비어 있는 단원(`"cards": []`)은 앱에 "준비 중"으로 보입니다.

## 예전 앱들

`tonggwa-flashcard`, `chem-flashcard`, `flashcard-app`, `chem-equilibrium`, `n2o4-equilibrium`은 그대로 두었습니다. 학생이 열면 맨 위에 **「새 앱으로 옮겼어요 → 새 앱 열기」** 안내가 보입니다. 통합과학·화학 플래시카드의 틀린 문제 기록은 새 앱으로 자동으로 옮겨집니다.
