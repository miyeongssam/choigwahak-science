2026-10-19 추가 변경
- 디자인: 검정 바탕 + 회색 카드 + 파스텔 포인트(`common/common.css`). 평형 앱 2개(`eq-kt`, `n2o4`)는 원래 밝은 디자인 그대로.
- 원소 기호 게임 → 「원소 기호 · 화학식 게임」: 원소 · 이온식 · 화학식 · 이온화식 · 화학 반응식, 교재 단원(통합과학1 84~140쪽 / 통합과학2 64~88쪽) 선택, 휴대폰 한 화면.
- 이온식 퍼즐: 휴대폰 한 화면(양이온 · 음이온 · 조립칸이 스크롤 없이).
- 데이터 출처: 하이탑 고등과학 통합과학1(84~140쪽), 통합과학2 산화와 환원(64~75쪽) · 중화 반응(80~88쪽).

기존 앱 5개(`tonggwa-flashcard`, `chem-flashcard`, `flashcard-app`, `chem-equilibrium`, `n2o4-equilibrium`)는 지우지 않고 맨 위에 「새 앱으로 옮겼어요」 안내만 넣었다.

## 고칠 때 규칙

- 앱 기능을 바꾸면 `sw.js`의 `VERSION`을 올린다(v1 → v2).
- 새 앱은 폴더 하나 + `apps.json`에 한 줄. 공통 디자인은 `common/common.css`, 문제 풀이 화면은 `common/common.js`의 `CS.QuizRound`.
- 암기 문제 추가 방법은 `README.md` 참고.
