## 다음 순서

1. 브랜치를 `main`에 합치기(GitHub Pages가 main 기준이면 합쳐야 학생 주소에서 보임).
2. 원장님 휴대폰(아이폰·안드로이드)과 칠판 TV에서 직접 열어 보기.
3. 원장님 확인이 필요한 과학 내용(아래)을 결정한 뒤 한 번에 수정.
4. 비어 있는 단원 파일 24개 채우기(통합과학 20개, 화학 4개).

## 원장님 확인 필요

| 번호 | 앱 | 확인할 것 |
|---|---|---|
| 1 | 이온식 퍼즐 | 문제에서 뺀 9개 조합(AgOH, NH₄OH, (NH₄)₂O, (NH₄)₂S, CuI₂, FeI₃, Fe₂S₃, Fe₂(CO₃)₃, Al₂(CO₃)₃)이 맞는지, 오답 보기에 실제 다른 물질 이름(질화, 아황산 등)을 써도 되는지 |
| 2 | 중화 반응 | H₂SO₄ + Ca(OH)₂는 앙금(황산 칼슘)이 생길 수 있어 문제에서는 빼고 실험 화면에서는 안내 문구로 허용 |
| 3 | 도플러 | 음속 돌파일 때 뒤쪽 관찰자도 「공식 적용 안 됨」으로 표시함(엄밀히는 멀어지는 쪽 식은 성립) |
| 4 | 파동 간섭 | 경계 경우 파원 위치는 마디 수에서 빼고 셈 |
| 5 | 전자 전달계 | 두 막 모두 H⁺가 쌓이는 쪽을 위에 그림(교재에 따라 엽록체는 스트로마를 위에 그림) |
| 6 | TCA 회로 | 숙신산/석신산 표기, 「5탄소·4탄소 화합물」 단순 보기를 기본으로 둔 것, 해당 과정 장소 「세포질」 |
| 7 | 그래프 도구 | 옴의 법칙 예시 축(x = 전압, y = 전류), 원점 직선 R² 계산 방식(엑셀과 같음) |
| 8 | 암기 문제 데이터 | 통합과학1 「중력장 내의 운동」의 "자유낙하하는 물체의 매초 이동 거리는? → 제곱으로 증가" 카드: 매초(1초 동안) 이동 거리는 1:3:5…로 일정하게 증가하므로 정답 확인 필요 |

## 고칠 때 규칙

- 앱 기능을 바꾸면 `sw.js`의 `VERSION`을 올린다(v1 → v2).
- 새 앱은 폴더 하나 + `apps.json`에 한 줄. 공통 디자인은 `common/common.css`, 문제 풀이 화면은 `common/common.js`의 `CS.QuizRound`.
- 암기 문제 추가 방법은 `README.md` 참고.
